Questions

Is Vanta free?

Yes. Vanta is free and open source under the GPL-3.0-or-later license.

Do I need a Microsoft account?

Not right now. Vanta uses offline accounts (just a username) while Microsoft sign-in is coming soon. The same username always keeps the same player, so your inventory and progress stay with you. Microsoft sign-in will be needed for online servers, skins and Realms.

Can I play offline?

If an account has signed in and verified ownership before, Vanta can launch it without a connection. Online servers still need a working session.

Does Vanta collect any data?

No. There is no telemetry or analytics. Vanta only talks to Microsoft, Mojang, the mod loader sites, Modrinth and GitHub (for updates).

Where are my worlds stored?

Each instance has its own folder inside Vanta's data directory. Use “Open folder” on any instance to find it.

macOS?

Not yet. Vanta is built for Windows and Linux first.
