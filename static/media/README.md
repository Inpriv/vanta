# Vanta launcher captures

These files were captured from the real Windows **Vanta.exe v2.2**, running on this Arch Linux machine with **wine-11.20** on GNOME / XWayland. They are not HTML mockups or AI-generated images.

- Source executable: the published 101,393,920-byte Windows release.
- SHA-256: `1d31c80dc906233ab67597223b27293c9959fba9946f99a52a49451a610af949`.
- Only Vanta's application windows were captured; desktop contents and other apps were excluded.
- The demo nickname is `notch`. The previous nickname and settings were restored after capture.
- `launcher-home.webp`: compact launcher, 364 × 216.
- `launcher-settings.webp`: settings drawer, 704 × 216.
- `launcher-mods.webp`: actual Modrinth browse results, 704 × 464.
- `launcher-versions.webp`: version picker, 364 × 356, including its real popup window at its captured screen position.
- `launcher-tour.mp4` and `launcher-tour.webm`: the same 14-second, 30 fps recording, 704 × 464, without audio. The application is centered in a fixed canvas while its window animates.
- `launcher-preview.gif`: an abbreviated 12 fps preview for GitHub README rendering.
- `launcher-tour-poster.webp`: a real screenshot used before video playback.

The video demonstrates launcher controls only; it does not show Minecraft gameplay or establish performance benchmark results. Website video playback is paused offscreen and does not start automatically when reduced motion or data saving is enabled.
