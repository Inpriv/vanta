A small, free Minecraft launcher for Windows. MIT-licensed, around a hundred megabytes, no Microsoft account, no telemetry. Built because every other launcher I tried eventually wanted to be a game store.

Download for Windows View source on GitHub

What it is

Vanta is a launcher that gets out of your way. You pick a username and a Minecraft version and you press play. No installer wizard, no account migration, no "free trial" that needs your credit card.

Each Minecraft version lives in its own folder under .Vanta/instances/, so saves and mods don't fight each other. Fabric is set up automatically the first time you launch a version that supports it, and the Performance toggle adds Sodium, Lithium, Ferritecore and Mod Menu without you having to know what those are.

The launcher writes nothing outside its own folder. No Microsoft token, no telemetry, no analytics endpoint. You can grep the whole codebase on GitHub — it's a single Python file around ten thousand lines.

Get the launcher

Windows 10 and 11. The installer is a single executable; nothing else gets downloaded at install time. You'll need Java if you don't already have it — Vanta will tell you.
