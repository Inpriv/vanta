FAQ

Common questions.

Is Vanta really free?
Yes. Vanta is MIT-licensed open source on GitHub. No ads, no premium tier, no telemetry — and no plans to add any. If you paid for it, you were scammed.
Do I need a Microsoft account?
No. Vanta derives a stable UUID from your username with the same scheme as vanilla offline mode, so whitelists, stats and playerdata persist. Skins are shown from minotar.net.
Which Minecraft versions are supported?
All of Java Edition — from 26.2 back through 1.21, Beta, Alpha, Infdev, Indev and Classic. Performance Mode and Fabric mods need 1.14 or newer.
Do I need to install Java?
No. Vanta uses the exact Java runtime Mojang specifies for each version (Java 25 for 26.x, 21 for 1.20.5+, and so on) and downloads it on first launch. No admin rights, no PATH fiddling.
Where are my worlds and mods stored?
Each version has its own folder at %APPDATA%\.Vanta\instances\<version>\. Use the Mods tab, or drop jars into that version's mods folder.
Windows flagged Vanta — is it safe?
Defender's heuristics sometimes flag unsigned single-file programs. Vanta is fully open source, so you can audit every line, and you can check your download against the SHA-256 below. The standalone ZIP on the releases page is the most antivirus-friendly option.
